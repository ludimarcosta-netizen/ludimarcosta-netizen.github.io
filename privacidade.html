Política de Privacidade do Jarvis

Última atualização: 7 de outubro de 2026

Quem usa

O Jarvis é um assistente pessoal de uso privado. O único usuário é o próprio dono da conta Google que autorizou o acesso. O aplicativo não é oferecido ao público.

Quais dados do Google são acessados

Com a autorização do usuário, o Jarvis pode ler e gerenciar e-mails do Gmail, eventos da Agenda, arquivos do Drive, Documentos, Planilhas e ler os Contatos, apenas para atender pedidos feitos pelo próprio usuário (por exemplo, "quais os meus compromissos de hoje?").

Como os dados são usados e guardados

  • Os dados são processados no computador do usuário e usados só para responder aos pedidos dele.
  • A credencial de acesso fica armazenada localmente nesse computador.
  • Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros.
  • Trechos necessários para responder a um pedido podem ser enviados ao provedor do modelo de inteligência artificial usado pelo assistente, apenas para gerar a resposta.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
